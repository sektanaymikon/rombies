ROMBIES — SMALL CODEHS PACKAGE

Upload this ZIP to your HTML website project. Keep index.html, style.css,
assets.js, data.js, game.js and the assets folder together.
All game features, sprites and story scenes are included. Images have been
resized and compressed for the game canvas; original source files are preserved.
Controls: A/D move, W jump, Shift sprint, 1-4 moves, Space ultimate,
C dodge, Tab switch, E interact, Escape pause/skip dialogue.
